# 📜 Certificate Generation Portal (PHP Project)

## 📌 Project Overview
This is a **Certificate Generation Web Application** built using **PHP, HTML, CSS, and MySQL**.  
It allows users to register, login, and generate certificates dynamically.  
An admin panel is also provided to manage users, logs, and system activities.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login
- Forgot Password functionality
- Dashboard for users
- Generate certificates
- Download certificates as PDF
- Help & About pages

### 🛠️ Admin Features
- Admin Login Dashboard
- View all users
- Monitor login logs
- Track certificate generation logs (PDF logs)
- Change admin password
- View average time reports

## 🖥️ How to Run the Project

1. Install XAMPP / WAMP
2. Copy project folder into:
   ```
   htdocs/
   ```
3. Start Apache & MySQL
4. Import database (if SQL file provided)
5. Open browser and run:
   ```
   http://localhost/hamaraproject/
   ```
